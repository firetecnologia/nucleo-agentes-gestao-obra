# Automacao Segura

## Ordem

- Validar testes.
- Ativar leitura.
- Preparar fila.
- Executar itens aprovados.

## Premissas

- Primeiro validar.
- Depois ler.
- Depois sugerir.
- Depois executar com liberacao.

## Rotina

A rotina deve gerar resumo diario, lista de pendencias e fila de itens para revisao.
